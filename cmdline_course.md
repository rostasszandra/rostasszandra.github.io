## Introduction

In this course, I learned to work efficiently in a command-line environment using a powerful set of tools for scripting, text processing, software management, and more. 

**Course format:** This is an online course with lecture videos that can be watched at your own pace, supplemented by local practice on the machine and in-person support sessions for hands-on assistance.

---

## Week 1: Introduction to Command Line Environments
During the first week, we explored the fundamentals of the Unix shell, file system navigation, and basic terminal commands (`cd`, `ls`, `pwd`).

---

## Week 2: Text Processing in UNIX
Week 2 focused on powerful text manipulation and filtering tools like `grep`, `sed`, and `awk` for processing data directly from the terminal.

---

## Week 3: Scripting, Configuration Files and Installing Programs
In this week, we covered writing scripts, managing configuration files, and installing software packages to streamline development workflows.

---

## Week 4: Using ssh, scp and Version Control
The final week covered remote connections using `ssh` and `scp`, alongside version control practices and deploying projects with GitHub Pages.
